# Project Kickstart — ابدأ أي مشروع بالطريقة الصح مع الذكاء الاصطناعي

سكيل لـ Claude، ومعاه برومبت مستقل لأي Agent تاني. بيسألك عن مشروعك بلغتك، ويكتب الملفات الأساسية اللي أي Agent هيمشي عليها، ويرفع كل حاجة على GitHub، ويشرحلك اللي جاي.

## ليه؟

الـ AI Agents ما بيفتكروش الجلسات اللي فاتت. أي حاجة مش مكتوبة بيخمّنوها، وكل تخمينة بتطلع كود مختلف شوية. ومع الوقت المشروع بيبقى كود سباجيتي.

السكيل ده بيحل المشكلة قبل أول سطر كود. بيكتب **إيه** اللي هنبنيه، و**بأي ترتيب**، و**بأي تقنيات**، و**القواعد** اللي أي Agent لازم يمشي عليها، والاختبارات اللي لازم تنجح قبل الانتقال لأي مرحلة جديدة.

## بيعمل إيه

1. **يسألك أسئلة بسيطة** بلغتك ولهجتك، 3–5 في المرة، ويتخطى اللي مش بيخص مشروعك.
2. **يساعدك لو قلت «مش عارف» أو «مش فاهم»:** يشرحلك بمثال من مشروعك، ويرشحلك اختيار، ويسجله كافتراض تقدر تغيّره بعدين.
3. **يبص على الجاهز عندك قبل ما يسأل:** الموقع الحالي، الشعار، التصميمات، السيرفر (قراءة بس وبإذنك).
4. **يكتب ملخص للمشروع** ويستنى موافقتك.
5. **يختار التقنيات** ويتأكد من آخر إصداراتها الحقيقية وقتها.
6. **يكتب الملفات على قد المشروع:** صغير (5 ملفات)، متوسط، أو كبير (المجموعة كاملة). والأهم خطة بمراحل صغيرة، وكل مرحلة ليها **اختبارات لازم تنجح** قبل اللي بعدها.
7. **يجهّزك على GitHub** خطوة بخطوة: يشرحلك ليه، ويساعدك تعمل الحساب (الباسورد بتكتبه إنت)، ويربط جهازك، ويعمل مستودع **خاص**، ويرفع الملفات.
8. **يسلّمك خطة واضحة** للي جاي.

## التركيب

### Claude Code
```bash
git clone https://github.com/motalim-ai/project-kickstart ~/.claude/skills/project-kickstart
```
وبعدين في أي فولدر جديد قول: **«عاوز أبدأ مشروع جديد»**، أو اكتب `/project-kickstart`.

### تطبيق Claude أو Claude.ai
نزّل ملف `project-kickstart.skill` من [آخر إصدار](https://github.com/motalim-ai/project-kickstart/releases/latest)، وضيفه من **Settings ← Capabilities ← Skills**.

### أي Agent تاني (ChatGPT, Cursor, Codex, Gemini…)
انسخ محتوى [`PROMPT.md`](PROMPT.md) والصقه في أول رسالة.
